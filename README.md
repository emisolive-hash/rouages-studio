# Rouages Studio

Rouages Studio fabrique tes vidéos **sur ton PC, tout seul** : voix, rendus 3D Blender et vidéos MP4.
Tu peux mettre en pause à tout moment pour libérer le PC, puis reprendre **à l'image exacte**, sans rien perdre.
Avec une clé Claude (facultative), il propose aussi des idées, écrit les vidéos et construit les scènes 3D.

## Installer (Windows)

1. Bouton vert **Code › Download ZIP**, puis décompresse le dossier où tu veux.
2. Double-clique sur **`Rouages-Studio.bat`**. Il installe ce qui manque et crée le raccourci « Rouages Studio » sur le Bureau.
3. Le guide de démarrage s'ouvre : 5 petites étapes, tout est expliqué.

Tu préfères que Claude s'en charge ? Dans le guide, choisis « Claude l'installe pour moi ».

La notice complète se trouve dans [GUIDE.md](GUIDE.md), et aussi dans l'app (roue dentée › Notice).

## Ce qu'il faut

- Windows 10 ou 11, avec une carte graphique récente (pour Blender).
- Node.js, Blender et ffmpeg, que le guide installe pour toi.
- Facultatif : Git (si la liste des vidéos à faire est sur GitHub), Python (pour générer les voix), une clé API Claude.

## Vie privée

Tout tourne sur ton PC. Tes réglages et ta clé Claude restent dans le dossier `donnees`, qui ne se partage jamais.
L'app n'envoie rien ailleurs qu'à Claude (seulement si tu mets une clé) et à ta propre file de tâches.
